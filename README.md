# 📈 ژورنال معاملاتی فارکس

برنامه‌ی دسکتاپ، **کاملاً فارسی، آفلاین و خصوصی** برای ثبت و تحلیل معاملات. همه‌ی داده‌ها فقط روی کامپیوتر خودت (SQLite) ذخیره می‌شود.

## اجرا در VS Code (برای توسعه)
1. Python 3.10 یا بالاتر نصب باشد (هنگام نصب تیک **Add Python to PATH** را بزن).
2. پوشه‌ی پروژه را در VS Code باز کن و در ترمینال بزن:
   ```
   pip install -r requirements.txt
   python main.py
   ```
   (یا فقط روی `run.bat` دابل‌کلیک کن.)

## ساخت فایل نصبی ویندوز (Setup.exe)
1. [Inno Setup 6](https://jrsoftware.org/isdl.php) را نصب کن (رایگان، فقط یک‌بار).
2. روی `build_installer.bat` دابل‌کلیک کن.
3. خروجی: `installer_output\ForexJournal_Setup.exe` ← این فایل را روی هر ویندوزی نصب کن؛ نه پایتون لازم است، نه اینترنت.

> اگر Inno Setup نصب نباشد، نسخه‌ی قابل‌حمل در `dist\ForexJournal` ساخته می‌شود (ForexJournal.exe).

## امکانات
- **داشبورد**: سود/زیان، نرخ برد، Profit Factor، میانگین R، افت سرمایه، منحنی سرمایه، نمودار ماهانه
- **ثبت معامله**: تاریخ شمسی، نماد، خرید/فروش، SL/TP، پیپ و R خودکار، سشن، استراتژی، حال ذهنی، رعایت پلن، ستاره‌ی کیفیت، اشتباهات، یادداشت، اسکرین‌شات (با Ctrl+V از کلیپ‌بورد: Win+Shift+S)
- **مربی هوشمند**: تشخیص معاملات انتقامی، پرمعامله‌گی، گران‌ترین اشتباه، بدترین ساعت/روز/نماد، اثر احساسات و…
- **تحلیل عمیق**: ۱۰ نمودار (نماد، روز، ساعت، سشن، استراتژی، احساس، پلن، اشتباهات…)
- **تقویم شمسی** رنگی + **دفتر روزانه** (حال روز و یادداشت)
- **ماشین‌حساب ریسک** (حجم معامله از روی درصد ریسک)
- پشتیبان‌گیری، بازیابی، خروجی CSV برای اکسل
- میانبر: `Ctrl+N` = معامله‌ی جدید

## محل ذخیره‌ی داده‌ها
`%APPDATA%\ForexJournalPro` (از تنظیمات هم قابل‌باز کردن است). حذف برنامه، داده‌هایت را پاک نمی‌کند.
